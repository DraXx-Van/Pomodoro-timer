# FOCOSPOINT - Pomodoro Timer & Task Manager

A sleek, dark-themed Pomodoro timer and task management web application designed to help you stay focused and productive. 

## 🚀 Features

- **Pomodoro Timer**: Pre-configured modes for Focus Sessions (25 mins), Short Breaks (1 min), and Long Breaks (15 mins).
- **Task Management**: Add, track, and complete tasks as you work.
- **Task Filtering**: Easily view All, Active, or Done tasks.
- **Session Tracking**: Automatically tracks the number of focus sessions completed and total focus minutes.
- **Time Adjustment**: Quickly add 10 seconds to your timer when you need just a little more time.
- **Interactive Background**: Beautiful dynamic canvas background that reacts to your window size.

## 🛠️ Technologies Used

- **HTML5**: Structure and semantics.
- **CSS3**: Custom variables, responsive design, and smooth animations.
- **Vanilla JavaScript**: DOM manipulation, interval timers, and state management without external libraries.

## 💻 Running Locally

Simply clone the repository and open `index.html` in your favorite browser. No build steps or local servers are required!

```bash
git clone https://github.com/DraXx-Van/Pomodoro-timer.git
cd Pomodoro-timer
```

Open `index.html` directly in your browser.

## 🎨 Modes Overview

- **FOCUS**: 25 minutes - Your core working time.
- **SHORT BREAK**: 1 minute - A quick breather.
- **LONG BREAK**: 15 minutes - A longer rest after multiple focus sessions.
